## 📋 Guide de Migration vers InfinityFree

### Étape 1 : Créer le compte

1. Allez sur [infinityfree.net](https://www.infinityfree.net)
2. Cliquez sur **"Sign Up"** ou **"Create Account"**
3. Remplissez le formulaire
4. Vérifiez votre email

### Étape 2 : Créer votre site

1. Connectez-vous au panel InfinityFree
2. Cliquez sur **"Create Account"** → **"Create Free Account"**
3. Choisissez un nom pour votre site (ex: `projetclinique`)
4. Vous obtenez : `projetclinique.infinityfreeapp.com`

### Étape 3 : Uploader vos fichiers

**Option A : Via cPanel File Manager**
1. Connectez-vous à cPanel
2. Allez dans **"File Manager"**
3. Uploadez tous vos fichiers dans `public_html`

**Option B : Via FTP**
1. Utilisez FileZilla ou un client FTP
2. Connectez-vous avec les identifiants FTP fournis
3. Uploadez vos fichiers dans `public_html`

### Étape 4 : Créer la base MySQL

1. Dans cPanel, allez dans **"MySQL Databases"**
2. Créez une nouvelle base (ex: `projetclinique_db`)
3. Créez un utilisateur MySQL
4. Assigne l'utilisateur à la base
5. Notez les identifiants :
   - Host : `localhost` (ou l'host fourni)
   - Database : `projetclinique_db`
   - User : `projetclinique_user`
   - Password : (celui que vous avez créé)

### Étape 5 : Configurer votre application

Modifiez `config/bdd.php` pour utiliser les identifiants InfinityFree :

```php
// Pour InfinityFree, utilisez les variables d'environnement ou les valeurs directes
$server = 'localhost'; // ou l'host fourni par InfinityFree
$dbname = 'projetclinique_db';
$username = 'projetclinique_user';
$password = 'VotreMotDePasse';
```

### Étape 6 : Importer votre base de données

**Option A : Via phpMyAdmin**
1. Dans cPanel, ouvrez **phpMyAdmin**
2. Sélectionnez votre base
3. Cliquez sur **"Import"**
4. Uploadez votre fichier `export_for_render.sql`

**Option B : Via script PHP**
1. Créez un fichier `import.php` à la racine
2. Utilisez le script d'import similaire à `import_on_render.php`
3. Accédez à `https://projetclinique.infinityfreeapp.com/import.php`

### Étape 7 : Tester votre site

1. Allez sur : `https://projetclinique.infinityfreeapp.com`
2. Testez la connexion : `https://projetclinique.infinityfreeapp.com/login.php`
3. Vérifiez que tout fonctionne

## 🔧 Configuration pour InfinityFree

### Variables d'environnement

InfinityFree ne supporte pas toujours les variables d'environnement. Modifiez directement `config/bdd.php` :

```php
function bdd() {
    // Pour InfinityFree (production)
    if (getenv('INFINITYFREE_HOST')) {
        $server = getenv('INFINITYFREE_HOST');
        $dbname = getenv('INFINITYFREE_DATABASE');
        $username = getenv('INFINITYFREE_USER');
        $password = getenv('INFINITYFREE_PASSWORD');
    } else {
        // Valeurs par défaut pour InfinityFree
        $server = 'localhost';
        $dbname = 'projetclinique_db';
        $username = 'projetclinique_user';
        $password = 'VotreMotDePasse';
    }
    
    // ... reste du code
}
```
